Kalau semua hijau, langkah berikutnya

  1. Build PWA: cd frontend && npm ci && npm run build
  2. Upload isi frontend/dist/ ke docroot, menimpa index.html ini.
  3. Backend FastAPI tetap di VPS, satu origin dengan PWA: nginx menyajikan / dan mem-proxy /api/ (lihat deploy/DEPLOY.md). Shared hosting tidak bisa mem-proxy /api/ — halaman ini di shared hosting hanya menguji domain/docroot.
